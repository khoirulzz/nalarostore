# Nalaro Store audit, 15 October 2026

## Code changes

- The readiness endpoint executes read-only application-schema queries before reporting a connected database. Missing Hyperdrive or a schema/query failure produces HTTP 503; liveness remains independent.
- Owner approval can grant exactly six calendar months for a selected UMKM store. Short 0–90 day pilots and revocation remain supported. Mixed or arbitrary month durations are rejected. The approval and expiry are written atomically to the audit trail. This enables pilot access for stores without an existing subscription; it does not replace an existing paid subscription or publish a draft store.
- Product updates reject repeated variant IDs before touching inventory or stock history.
- Order filters use strict calendar dates shared with analytics, including leap-year validation.
- Media URL validation returns a controlled validation error for malformed URLs and rejects embedded credentials.
- Public pricing no longer displays internal campaign instructions. UMKM application briefs use actual line breaks.
