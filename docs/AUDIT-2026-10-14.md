# Hasil perbaikan MVP dan Firebase Auth

## Perubahan

- Firebase SDK untuk daftar/login/verifikasi/reset/perubahan kata sandi; endpoint password lama tidak lagi menerima autentikasi.
- Worker memverifikasi signature RS256, issuer, audience, expiry dan account lookup. UID menjadi hubungan identitas; merchant membership dan hak owner tetap diverifikasi di server.
- Kebijakan kata sandi dibaca dari Firebase. Konfigurasi proyek nyata dibaca tanpa membuat akun: ENFORCE, 8–4096 karakter, besar/kecil/angka wajib, simbol opsional. Localhost sudah berada dalam Authorized Domains.
- Localhost UI/API terpadu dengan PGlite atau Aiven, URI/kolom koneksi, verifikasi CA, migrasi eksplisit, upload lokal dan emulator yang terpisah dari proyek nyata.
- Tracking tetap tersedia setelah toko dijeda/expired; QRIS tracking dibatasi oleh token pesanan.
- Status custom menyimpan kode status yang benar; masa pilot harus ditentukan admin dan memiliki batas waktu.
- Slug otomatis/cek ketersediaan, preview draft berizin, checklist publikasi, kontak/kebijakan toko, galeri dan gambar varian.
- Pencarian/filter tanggal/pagination pesanan, ringkasan pelanggan, analitik pendapatan dasar, ekspor CSV dan cetak ringkasan pesanan.
- Retry notifikasi gagal oleh admin dan penanganan outbox yang tertahan pada percobaan terakhir.
- Metadata HTML toko/produk, canonical, Open Graph, structured data dan noindex halaman privat/demo.

## Validasi yang dijalankan

- `npm run check` lulus: generated binding types, pemeriksaan skema, TypeScript, 25 tes lulus, build.
- Satu tes restore native PostgreSQL dilewati di lokal karena membutuhkan konteks Docker/PostgreSQL CI.
- Tiga Playwright E2E lulus memakai Chrome lokal dan Firebase Auth Emulator: transaksi sampai pickup selesai/tracking saat toko dijeda, layout 320/390/768/1440, daftar/verifikasi/reset/perubahan kata sandi.
- `wrangler deploy --dry-run` lulus; tidak ada deployment dari perintah ini.
- Aiven melalui konektor: RUNNING, PostgreSQL 17.11, public schema kosong.
- Cloudflare melalui konektor: R2 nalarostore-media ada; daftar Hyperdrive kosong.

## Batas hasil

Perubahan berada di working tree; belum dipush, belum dimigrasikan ke Aiven dan belum dideploy produksi. Tes emulator tidak membuktikan pengiriman email nyata, kesiapan DNS/TLS atau perilaku pada perangkat fisik. Metadata Worker sudah lolos typecheck/bundling, belum diuji melalui Hyperdrive produksi.

Firebase mengizinkan localhost dan nalarostore.nalaro.digital; store.nalaro.digital belum masuk Authorized Domains. Konfigurasi domain produksi perlu diselaraskan sebelum rilis. Harga/kontrak/privasi/dukungan, Hyperdrive, notifikasi nyata, load/restore produksi, MFA provider review, full SSR dan integrasi fase berikutnya tetap tercantum sebagai pekerjaan terbuka pada ROADMAP.md.
